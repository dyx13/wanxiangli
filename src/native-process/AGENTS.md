# 两个物理入口共享的私有I/O

只有`BunProcess.fs`，由Process和Supervision两个工程明确编译，没有npm入口。它转换实际Bun.spawn、FileSink、输出流及spawn/exit/close事件，拥有每个child的I/O接线状态；不保存ProcessSession状态、监管账本、业务完成或持久归属。

detached由调用方明确传入：基础会话拥有独立进程组，监管目标留在Worker组内。stdin等待FileSink write及flush完成，再以setImmediate离开原生drain回调后发布成功，防止下一块write/end在原生微任务检查点重入。成功发布前保留待决写入；错误或确认前exit即时裁决Unknown，排队的成功不得覆盖。即时计数不代表尚未刷出的内部缓冲，不补写。exit不代替两路输出关闭。共享只为删除真实重复I/O实现，不引入通用服务树或可配置后端框架。

输出使用非阻塞FIFO读端与独立阻塞写端。每路Readable队列最多128KiB，另有64KiB私有scratch与一个重试任务；只因真实EAGAIN重调度，收到字节后重置，真实正长度read零才EOF。所有输出准备和匿名化发生在目标spawn前；Bun显式依赖/usr/bin/mkfifo及支持FIFO的临时文件系统。缺前提明确失败，不回退无界原生pipe。

准备失败要清本次资源，清理未确认必须进入可见失败，不能异步击穿Host。spawn后的父writer关闭失败保留真实Started/pid并报告I/O失败，不能重发。Worker借用1/2的有界Writable等全部write计数与flush，不end全局fd。验收由真实暂停写者、32空闲读、部分读取恢复、取消/同号fd复用、ENOENT/清理失败、完整输出与精确包承担；平台与总RSS边界分别说明。
